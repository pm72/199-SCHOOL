
### დავალება 1.

შეასწორეთ შესაბამისობა:

```
< – მეტია ან ტოლი
> – არ არის ტოლი
<= – ნაკლებია
>= – შემოწმება ტოლობაზე
== – ნაკლებია ან ტოლი
!= – მეტია
```
